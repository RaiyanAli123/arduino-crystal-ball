# Crystal Ball — Arduino UNO R4 WiFi

An interactive prediction device built with an Arduino UNO R4 WiFi.

## Overview

Crystal Ball takes user input and generates randomized responses displayed
through the LCD.

## Hardware

- Arduino UNO R4 WiFi
- LCD display
- Push button / input sensor
- Jumper wires
- Breadboard

## Features

- User input detection
- Randomized responses
- LCD output
- Arduino C/C++ firmware

## How It Works

1. User provides input.
2. Arduino detects the input.
3. The program generates a randomized response.
4. The response is displayed on the LCD.

## Technologies

- Arduino C/C++
- Arduino IDE
- Arduino UNO R4 WiFi
